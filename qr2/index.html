Como criar um menu misto (links diretos + submenus):
• Para um link direto no topo, preencha Nome e Link e deixe Item pai como "Nenhum".
• Para criar um submenu, primeiro cadastre o item de topo (pode deixar o link em branco). Depois, ao cadastrar um novo item, selecione esse item como Item pai. O sistema detecta automaticamente: itens com filhos viram botões de submenu; itens sem filhos viram links diretos.
• Os subitens sempre aparecem como links dentro do menu expandido.
